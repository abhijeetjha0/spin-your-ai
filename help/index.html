Spin Your AI : Help Center

1. Getting Started

Spin Your AI allows you to connect to multiple AI models simultaneously. To start chatting:

  • Open the Settings page by clicking the gear icon in the sidebar.
  • Enter your API Keys for the providers you wish to use (e.g., OpenAI, Anthropic).
  • For local providers like OpenCode or Ollama, ensure your local server is running and the Host URL is correct.

2. Using the Side Panel

The main chat interface lives directly inside your browser's side panel.

  • Select a Model: Click the model dropdown at the top of the chat panel to switch between available AIs.
  • Include Page Context: Toggle the "Include page content" switch to let the AI read the webpage you are currently viewing.
  • Attachments: Click the paperclip icon to upload images, documents, or code files to send to multimodal models.
  • Clear Chat: Click the trash icon at the top to reset the conversation history.

3. Data Privacy & Security

Your data stays with you. Spin Your AI is designed as a secure, local-first extension.

  • All API keys and credentials are encrypted and stored entirely in your browser's local storage (`chrome.storage.local`).
  • Your keys are never synced to external cloud services or third-party servers.

4. Troubleshooting

If you encounter issues connecting to a provider:

  • Ensure you have sufficient API credits on your provider's dashboard.
  • Use the "Test" button on the Settings page to verify your credentials.
  • If using local MCP Servers, verify that the server URL is reachable.
